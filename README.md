# 🏏 Batsman Performance Analysis

## 📌 Project Overview

**Batsman Performance Analysis** is a data analytics project designed to analyze a batsman's batting performance and dismissal patterns using historical match-level data.

The project combines **Python, SQL, and Power BI** to transform raw cricket data into meaningful insights that help understand a batsman's scoring behavior, performance trends, and potential weaknesses against different bowling conditions.

---

## 🎯 Project Objective

The primary objective of this project is to analyze a batsman's performance from multiple perspectives, including:

- Overall batting performance
- Runs, balls faced, and strike rate
- Boundary contribution
- Performance across matches
- Dismissal patterns
- Performance against different bowling types
- Bowling speed and dismissal trends

The analysis aims to identify patterns that can provide useful insights into how a batsman performs and where potential weaknesses may exist.

## 🔍 Key Analysis Areas

### Batting Performance

Analysis of scoring patterns, strike rate, boundaries, and match-to-match performance.

### Dismissal Analysis

Identification of recurring dismissal patterns and the circumstances associated with them.

### Bowling Type Analysis

Comparison of the batsman's performance against different types of bowlers.

### Bowling Speed Analysis

Analysis of how performance and dismissals vary across different bowling-speed categories.

---

## 💡 Analytical Questions

The project explores questions such as:

- How consistent is the batsman's scoring performance?
- How significant is the contribution of boundaries to total runs?
- Does performance vary against different bowling types?
- Are dismissals concentrated against specific bowling categories?
- Is there an observable relationship between bowling speed and dismissals?
- Can recurring dismissal patterns indicate areas requiring further analysis?

> **Note:** Conclusions are based only on the available dataset and should not be treated as definitive predictions of future performance.

## 📌 Limitations

The analysis has some limitations:

- The dataset represents a limited set of historical observations.
- Bowling conditions, pitch conditions, match situations, and field placements may not be fully represented.
- Dismissal patterns alone cannot establish a definite weakness.
- More data would be required for statistically robust predictive modeling.
